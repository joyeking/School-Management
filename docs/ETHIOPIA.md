# EthioSIS — Ethiopian adaptation guide

This fork of RosarioSIS is adapted to the **Ethiopian school system** and ships a
modern theme, **EthioSIS**, plus an optional Ethiopian-calendar display layer.

Everything here is *additive*: the upstream RosarioSIS features keep working and
can be re-enabled at any time from the interface.

---

## 1. What was adapted

| Area | Before (US defaults) | After (Ethiopia) |
| --- | --- | --- |
| Currency | `$` | `Br` (Ethiopian Birr) |
| School name / address | Default School, Springfield IL | Addis Ababa Secondary School, Addis Ababa |
| Grade levels | KG + Grades 1–8 | **KG + Grades 1–12** |
| Marking periods | Summer-to-summer (June→June) | **September → June** (2 semesters × 2 quarters) |
| Grading scale | US `A+` / `A-` / 4.0 GPA | **A 90, B 80, C 70, D 60, F fail** |
| Student fields | Social Security, US Ethnicity, Language | SSN removed; **Region** (Ethiopian regions); **Mother Tongue**; **Stream** (Natural / Social Science) |
| Enrollment codes | "Moved from District" … | Transferred In/Out, Dropped Out, Graduated, Expelled |
| Site name | Rosario Student Information System | Ethiopian Student Information System |
| Theme | FlatSIS | **EthioSIS** (modern, responsive, dark-mode aware) |
| Calendar display | Gregorian only | **Ethiopian calendar display** (Gregorian storage) |

## 2. Applying the adaptation

### On an existing installation

Import the patch (it is safe to run more than once):

```bash
mysql -u root rosariosis < ethiopia.sql
```

or import `ethiopia.sql` through phpMyAdmin / Adminer.

Then enable the Ethiopian calendar for the site in `config.inc.php`:

```php
$EthiopianCalendar = true;
```

### On a fresh installation

1. Install RosarioSIS as usual (see `INSTALL.md`).
2. Run `ethiopia.sql` against the new database.
3. Add `$EthiopianCalendar = true;` to your `config.inc.php`
   (see `config.inc.sample.php`).

> The patch creates the **2026/2027** marking periods ahead of time. The default
> school year stays `2025` until you run **School Setup → Rollover**, which also
> creates the new-year user and school rows. After rollover set
> `$DefaultSyear = '2026'` in `config.inc.php`.

## 3. The Ethiopian calendar

Ethiopian schools work with the *Amete Mihret* calendar (13 months, "E.C.").
EthioSIS keeps every date **stored as Gregorian ISO** in the database — which
keeps all SQL, exports and reports correct — and converts only for **display**.

* Converter: `functions/EthiopianCalendar.fnc.php`
* Display hook: `functions/Date.php` → `ProperDate()`
* Per-user toggle: **Users → My Preferences → Display Options → “Ethiopian calendar dates”**
* Site default: `$EthiopianCalendar` in `config.inc.php`

Example: `2025-09-01` is shown as **26 Nehase 2017 E.C.** and the Gregorian value
is available as a tooltip on the date.

Conversion functions you can reuse:

```php
EthiopianFromGregorian( $year, $month, $day ); // ['year'=>, 'month'=>, 'day'=>]
GregorianFromEthiopian( $year, $month, $day );
EthiopianDate( '2025-09-01' );        // "26 Nehase 2017 E.C."
EthiopianDate( '2025-09-01', 'short' ); // "26 Neh 2017 E.C."
EthiopianDateISO( '2025-09-01' );      // "2017-12-26"
```

## 4. The EthioSIS theme

`assets/themes/EthioSIS/` is a drop-in theme (auto-discovered by the theme select):

* Emerald-green brand (`--brand: #0e7c5a`) with a restrained gold accent.
* System font stack, comfortable spacing, larger touch targets.
* Restyled tables, forms, buttons, messages, login page and side navigation.
* Automatic **dark mode** (`prefers-color-scheme`).
* Crisp **SVG** module icons and inline-SVG top action bar (no blurry PNGs).

The theme is plain CSS generated by the Grunt build (`Gruntfile.js`):

```
assets/themes/EthioSIS/stylesheet.css            # generated (legacy + overrides)
assets/themes/EthioSIS/stylesheet_wkhtmltopdf.css
assets/themes/EthioSIS/css/theme.css             # ← edit the modern styles here
assets/themes/EthioSIS/css/icons-svg.css
assets/themes/EthioSIS/modules/*.svg             # module icons
assets/themes/EthioSIS/logo.png                  # replace with your school logo
```

To change the look, edit the files under `css/` and rebuild the concatenated
stylesheet with `grunt` (or the same file order listed in `Gruntfile.js`).

## 5. Making it simpler

The side menu can be reduced to the modules an Ethiopian school actually uses:
**School Setup, Students, Users, Scheduling, Grades, Attendance**.

Either uncomment section 9 of `ethiopia.sql`, or use
**School Setup → Configuration → Modules** and untick the rest
(Eligibility, Discipline, Accounting, Student Billing, Food Service, Resources,
Custom). Modules can be re-enabled at any time.

---

## 6. Things to customise per school

* **School Setup → School Information** — name, address, principal, logo.
* **School Setup → Grading Scales** — adjust the A/B/C/D/F cut-offs if your
  region uses different bands.
* **School Setup → Marking Periods** — adjust semester/quarter dates.
* **Users → Preferences** — each user can turn the Ethiopian calendar on/off.
